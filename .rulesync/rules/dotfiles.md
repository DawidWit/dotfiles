# Dotfiles repository rules

This is a Chezmoi source repository for a personal macOS and Linux development environment. Windows is unsupported.

## Source layout

- Follow Chezmoi naming conventions: `dot_` maps to a leading dot, `private_` maps to private permissions, `executable_` marks an executable, and `.tmpl` files are rendered templates.
- `dot_local/bin/` holds installed user commands and `private_dot_config/` holds private XDG configuration.
- Blocks fenced by `generated by ~/.config/theme/apply.py -- do not edit by hand` in the Ghostty, Fish, and Zellij configuration are machine-generated colour output; regenerate them rather than editing them in place.

## Provisioning and safety

- `dotfiles-bootstrap` is the only command that installs packages or refreshes Chezmoi externals. Routine `chezmoi apply` only manages files and must never install packages.
- Ghostty launches Fish through `.config/zellij/bin/start-workspace`; `initial-command = direct:` takes a plain executable path with no quoting or shell syntax.
- Keep Bash scripts compatible with macOS Bash 3.2.
- Do not reintroduce unconditional AI permission bypasses, broad process-pattern kills, or tmux pane-content archive inspection.

## Agent-maintained files

- `.rulesync/rules/dotfiles.md` is the canonical RuleSync source. `AGENTS.md` and `CLAUDE.md` are generated, committed outputs; regenerate them with `pnpm rules:generate` and never edit them directly.
- Generate only the `agentsmd`, `codexcli`, and `claudecode` targets. Do not add a `GEMINI.md` target or output.
- `docs/superpowers/` contains local planning/specification artifacts only. It must remain local-only and must never be committed.

## Validation

Before completing a change, run, when available, `pnpm rules:check`, `shellcheck dot_local/bin/executable_* private_dot_config/zellij/bin/executable_*`, `shfmt -d -i 2 dot_local/bin/executable_* private_dot_config/zellij/bin/executable_*`, `stylua --check private_dot_config/nvim/lua`, `fish --no-execute` on the Fish files, and `git diff --check`.
